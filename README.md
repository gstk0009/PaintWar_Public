## 🎮 게임 소개

**PaintWar**는 최대 4명이 동시에 경쟁하는 실시간 영토 전략 배틀 게임입니다.

단순히 많은 타일을 점령하는 것이 아니라, **본진과 연결된 영토만 점수로 인정**됩니다.  
플레이어는 영토를 확장하는 동시에 상대의 연결부를 끊고, 끊어진 자신의 영토를 제한 시간 안에 복구해야 합니다.

> **핵심은 “얼마나 많이 칠했는가”가 아니라  
> “어떤 연결을 만들고, 지키고, 끊을 것인가”입니다.**

## 🏆 승리 조건

PaintWar의 점수는 단순 점령 수가 아니라 **본진과 연결된 유효 영토**를 기준으로 계산됩니다.

### 기본 규칙

- 본진과 연결된 유효 영토만 점수로 인정됩니다.
- 본진에서 멀리 떨어진 새로운 타일은 자동으로 중립화되지 않습니다.
- 이동으로 점령한 중립 타일은 자신의 영토가 됩니다.
- 상대 타일은 폭탄이나 스킬 등으로 중립화한 뒤 다시 확보할 수 있습니다.
- 기본 경기 시간은 **150초**입니다.
- 유효 영토 **500칸** 도달 시 즉시 우세 확보를 노릴 수 있습니다.
- 시간이 종료되면 더 유리한 영토 구조를 만든 플레이어가 승리합니다.

## 🔄 연결 · 절단 · 복구

PaintWar의 가장 중요한 메커니즘은 **영토 연결 구조**입니다.

**본진에서 시작** → **영토 확장** → **본진과 연결된 영역 확인** → **상대 연결부 절단**

- **3초 안에 복구 성공** → 영토 유지 → 다시 확장
- **3초 안에 복구 실패** → 끊어진 영역 중립화 → 다시 확장

### 플레이 감각

1. **시작과 확장**  
   본진에서 출발해 중립 타일을 점령합니다.

2. **연결 확인**  
   본진과 이어진 타일만 유효 영토로 계산됩니다.

3. **절단 발생**  
   상대가 연결부를 끊으면 해당 영역의 유효성이 사라질 수 있습니다.

4. **3초 복구 기회**  
   끊긴 연결을 제한 시간 안에 다시 이어 붙이면 영토를 유지할 수 있습니다.

5. **승리 판정**  
   제한 시간 동안 더 유리한 연결 구조와 영토를 만든 플레이어가 승리합니다.

## ⚔️ 전투 도구

전투는 상대를 쓰러뜨리는 목적이 아니라 **영토 구조를 바꾸기 위한 전략 수단**입니다.

### 💣 폭탄
- 장애물을 파괴하고 영역을 확보합니다.
- 연결 폭발을 활용하면 더 넓은 공간을 만들 수 있습니다.

### 🌀 텔레포트
- 지정한 위치로 순간 이동합니다.
- 위기 회피, 기습, 빠른 복구에 유용합니다.

### ⚡ 특수 스킬
- 강력한 효과를 가진 1회성 스킬입니다.
- 사용 후 쿨타임을 거쳐 다시 사용할 수 있습니다.

### 📦 아이템
- 전장 곳곳에서 획득하는 보조 도구입니다.
- 공격, 방어, 이동 등 전투 템포를 바꿉니다.

### 📈 레벨 성장
- 영토를 통해 경험치를 획득합니다.
- 레벨이 오르면 이동 속도, 스킬 쿨타임, 폭탄 사용 등이 강화됩니다.

## 🗺️ 맵 구조

맵은 플레이어의 확장과 충돌이 자연스럽게 발생하도록 구성되어 있습니다.

- 중앙에는 **십자형 장애물 구역**이 존재합니다.
- **회색 장애물은 파괴 가능**합니다.
- **보라색 장애물은 파괴 불가**입니다.
- 4개의 시작 구역은 서로 안전하게 분리되어 있습니다.
- 중앙으로 이동할수록 교전과 연결 절단 위험이 커집니다.
- 경기 후반에는 파괴 가능한 장애물이 사라지고 전장이 열리면서 경쟁이 더 빨라집니다.
